# 模型检测技术 — 竞品缺口分析（针对「模型保真测试」工具）

> 联网检索 7 个方向（学术指纹论文 / 验证与逆向检测工具 / 评测平台方法 / 量化降级检测 / 分词器与采样指纹 / 水印与文体学 / 实践者论坛），把网上约 97 项检测技术去重归并为约 18 类，逐一对照本工具现状。
> **结论**：本工具在 **协议 / 计量 / 能力真测 / 供应链渠道 / 加密签名回放** 上已是同类最强；主要缺口集中在 **tokenizer 指纹、分布统计检验、logprobs 路径** 三块，其中两块是低成本高价值。

## 2. 本工具已覆盖（无需重做）
TRAP 探针 · 身份一致性+拒绝风格 · 延迟分层 · 跨模型碰撞 · 换名检测 · **thinking 签名加密回放（≈轻量 attestation，这是杀手锏）** · 11+ 渠道指纹 · L1–L3 协议/计量/能力全套 · 单针 needle 上下文阶梯。

## 3. 关键缺口（按 价值/成本 排序）

**🔥 P0 低成本高价值（强烈建议立刻做）**
1. **Tokenizer 家族识别** — 复用已读取的 `usage.input_tokens`，发一批构造串（emoji/CJK/连续空格/长数字/生僻词）反推 cl100k / o200k / SentencePiece / Claude tokenizer。**声称 Claude 却命中 o200k = 铁证暴露 GPT 后端**。几乎零额外协议成本。黑盒✅，工作量低。
2. **Glitch/欠训练 token 探针**（SolidGoldMagikarp / petertodd / UTF）— 纯文本，发已知欠训练 token 看是否复现该家族特有乱码/复读。与 tokenizer 计数法互证。黑盒✅，工作量低。

**⭐ P1 中成本高价值**
3. **MMD 两样本分布检验**（Model Equality Testing, ICLR 2025）— 替代/补强现有 trigram-jaccard：对固定 ~25 prompt 各采 ~10 条，用官方直连或用户可信端点作参考分布做 Hamming 核 MMD 置换检验，给**统计显著性**，可靠抓量化/微调/换模型。黑盒✅（需参考分布）。
4. **修正 temperature=0 确定性误报** — 现逻辑把文本发散直接判「分流」，但同权重在生产 batch-variance 下 greedy 一致率也可 <5%（Berkeley / Thinking Machines 已证），**当前易误报**。建议降权 + 改「弱信号」文案。

**◾ P2 中价值**
5. **OpenAI 协议补 `system_fingerprint` + `seed` 双信号** — 仅读字段/重复请求，低成本；中转换后端常致 fingerprint 缺失或 seed 失效。
6. **条件性 logprobs** — OpenAI 兼容端点请求 `top_logprobs`，返回则跑 RUT 秩均匀/KL 检验（对量化极灵敏），不返回则降级到 MMD 文本法。
7. **碰撞升级为带 null 分布的派生假设检验**（输出 p 值）+ **单针→多针/RULER 子集**有效上下文检验。
8. **Tool-call schema 合法率**（Exacto 风格）+ **客户端 tiktoken 重算比对**计量。

**⛔ 不建议自建（黑盒不可达或违背工具定位）**
- 权重/梯度指纹（TensorGuard / Cisco）、TEE / TopLoc / DiFR attestation = 需白盒或 provider 配合，**纯前端不可达**（本工具签名回放已是最接近替代）。
- 学习型分类器（LLMmap / FDLLM）、benchmark 回归 = 需训练/大量查询，成本高、对量化弱，违背「无构建纯前端」定位，仅作进阶方向标注。
- owner 后门/水印指纹 = 只有模型所有者能植入，审计方做不了。

## 4. 优先落地步骤（映射到本仓库）
1. `js/prompts.js` 加 tokenizer 探针串组 + glitch token 组；`js/scorecard.js` 加 `l1_tokenizer_family` 与 `l6_glitch_token` 两个 check（内置各 tokenizer 计数表）。
2. `js/api.js` 加 MMD 采样套件（复用 `ConversationTask` 调度），参考分布走官方直连；`js/scorecard.js` 加 `l4_distribution_mmd`。
3. 调低 `l6_temp0_determinism` 权重并改文案；OpenAI 路径加 `system_fingerprint`/`seed` 读取与 check。
4. 升级 `l4_cross_model_collision` 输出 p 值；`l3_context_capacity` 扩多针。
5. 别忘 `index.html` 的 `?v=` 自增（当前 v59）。
